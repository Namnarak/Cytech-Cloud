## Overview

This repository stores **media resources**, rather than the source code for a hosting or cloud platform. It provides a convenient place to track and reuse project imagery and audio files.

## Available assets

| Asset | Description |
| --- | --- |
| `banner_bot.png` | Banner artwork |
| `image.png` | Image asset |
| `New_Project.mp3` | Audio asset |
| `warning_EN_sound.mp3` | English warning sound asset |
| `warning_TH_sound.mp3` | Thai warning sound asset |
| `assets/` | Additional media resources |

## Usage

Browse files from the [repository](https://github.com/Namnarak/Cytech-Cloud). Link to a specific file in the repository when using it in related project documentation.

> [!NOTE]
> This repository does not currently document an open license for its media. Public visibility alone does not grant permission to redistribute or relicense assets.
